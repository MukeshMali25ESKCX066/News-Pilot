# NewsPilot AI

NewsPilot AI is a lightweight end-to-end news automation system for collecting feeds, clustering similar stories, researching the story context, and generating article drafts.

## Features

- RSS source ingestion
- Duplicate detection and title normalization
- Story clustering by similarity
- Research summary generation
- AI-assisted article drafting with Gemini
- SQLite-backed tracking of sources, stories, and generated articles
- FastAPI APIs for source management and article creation
- Next.js dashboard frontend

## Quick start

Prerequisites: Python 3 and Node.js 20.9 or later.

1. Install the Python backend dependencies:
   `py -3 -m venv .venv`
   `.venv\Scripts\Activate.ps1`
   `py -3 -m pip install -r backend\requirements.txt`

2. Set up backend environment values:
   `if (-not (Test-Path .env)) { Copy-Item .env.example .env }`
   Add `GEMINI_API_KEY` to `.env` to enable article generation.

3. Start the Python API in one terminal:
   `Set-Location backend`
   `py -3 -m newspilot.main`

4. Start the Next.js frontend in a second terminal:
   `Set-Location frontend`
   `npm ci`
   `npm run dev`

5. Open the dashboard: `http://localhost:3000/`
   - API docs: `http://localhost:8000/docs`
   - Health check: `http://localhost:8000/health`

The Next.js dashboard talks to the Python API. In local development, Next.js proxies `/api/*` to `http://127.0.0.1:8000`; in production, Vercel proxies those requests to the Render backend configured in `vercel.json`. Only sources added in the dashboard are collected; no example feeds are added automatically. Hindi and English feeds are supported. Add an RSS/Atom URL, or a website URL that advertises its feed. Headlines and summaries are displayed in their original language. Drafts are not published automatically.

For deployment, keep the Vercel project root directory at the repository root. Its configuration installs and builds `frontend/` as a static Next.js export and forwards `/api/*` to the Render backend. The backend's canonical Python dependencies are in `backend/requirements.txt`; the root `requirements.txt` includes that file for hosts configured to install from the repository root.

## Project structure

- `frontend/` contains the Next.js app, React dashboard, and TypeScript types.
- `backend/` contains the Python FastAPI application, tests, and dependencies.
- Root `requirements.txt` includes `backend/requirements.txt` for hosts that install dependencies from the repository root.
- `wordpress-plugin/` contains the WordPress connector plugin.
- `vercel.json` builds the frontend and routes its API requests to the Python backend.
- `.env` and `data/` stay at the project root for local configuration and database storage.

Run backend tests from the backend directory:

`py -3 -m pytest tests\test_newspilot.py -q`

## Default workflow

Add sources in the dashboard. A collection cycle checks active sources, removes duplicates, and stores new news items. Story clusters are then generated by similarity and used to create article drafts.

## Notes

Set `GEMINI_API_KEY` in `.env` to generate complete original-language article drafts of approximately 1,000 words. Each draft gets a new headline and Yoast fields for SEO title, slug, meta description, focus keyphrase, excerpt, and tags. Source names and URLs are not sent as article citations. `GEMINI_MODEL` defaults to `gemini-3.5-flash-lite` and can be changed to another model available to your key. If the key is missing, generation reports a configuration error rather than saving a headline/excerpt as if it were a complete article.

To connect NewsPilot to WordPress with the NewsPilot Connector plugin:

1. In WordPress, go to **Plugins → Add New Plugin → Upload Plugin** and upload `wordpress-plugin/newspilot-connector.zip`. Install and activate **NewsPilot Connector**.
2. In WordPress, open **Settings → NewsPilot Connector** and copy the generated connector token. Keep it private.
3. In the NewsPilot `.env` file, set `WORDPRESS_SITE_URL` to the site's HTTPS address and `WORDPRESS_CONNECTOR_TOKEN` to the copied token. Restart NewsPilot; no WordPress username or Application Password is required.
4. Open `http://localhost:8000/wordpress/status`. It should report `"connected": true`. The article editor also checks the plugin connection before enabling **Push to WordPress**.
5. Test **Push to WordPress** with a draft first. Re-pushing an article updates its linked post. Automatic publishing is off by default; enable it only after confirming the draft reaches the right site.

The connector plugin creates posts, tags, and Yoast metadata through a token-protected REST endpoint. If the older **NewsPilot Yoast REST Bridge** is installed, deactivate it; the connector replaces it.
